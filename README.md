# Secure CLI Vault

This project provides a minimal prototype of a secure vault system with a Python CLI and an Express backend.

## CLI Usage

Install dependencies:
```
pip install pgpy cryptography click pymongo
```

Run the CLI:
```
python3 vault.py --help
```

## Backend

Navigate to `backend/` and install dependencies:
```
npm install
```
Run the server:
```
npm start
```
